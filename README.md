# homebrew-tap

Homebrew tap for [nife](https://github.com/mr-mister-bit/nife) and other tools.

## Установка

```sh
brew install mr-mister-bit/tap/nife
```

Или явно:

```sh
brew tap mr-mister-bit/tap
brew install nife
```

## Формулы

Формулы лежат в `Formula/`. Файл `Formula/nife.rb` соответствует команде `brew install mr-mister-bit/tap/nife`.
